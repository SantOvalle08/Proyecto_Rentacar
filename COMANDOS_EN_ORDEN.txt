┌────────────────────────────────────────────────────────────────┐
│ ANTES DE EMPEZAR - PREPARATIVOS (10 min)                      │
└────────────────────────────────────────────────────────────────┘

1. MongoDB Atlas:
   → Ve a: https://cloud.mongodb.com
   → Crear cuenta (usa Google para registrarte)
   → Create Database → M0 FREE
   → Crear usuario: admin
   → Network Access → Add IP: 0.0.0.0/0
   → Connect → Drivers → COPIAR connection string
   → PEGAR en Notepad
   → Reemplazar <password> con tu contraseña real

2. Google Cloud CLI:
   → Verificar si está instalado: gcloud version
   → Si no está, descargar: https://cloud.google.com/sdk/docs/install


┌────────────────────────────────────────────────────────────────┐
│ PASO 1: CONFIGURAR GOOGLE CLOUD (PowerShell)                  │
└────────────────────────────────────────────────────────────────┘

gcloud auth login

gcloud config set project proyectorentaca

gcloud config set compute/region us-central1


┌────────────────────────────────────────────────────────────────┐
│ PASO 2: CREAR ARCHIVO .ENV (Backend)                          │
└────────────────────────────────────────────────────────────────┘

cd C:\Users\santi\OneDrive\Desktop\Proyectos\GitHub\Proyecto_Rentacar\rentacar\back

@"
MONGODB_URI=TU-CONNECTION-STRING-DE-MONGODB-AQUI
PORT=8080
NODE_ENV=production
JWT_SECRET=mi-super-secreto-aleatorio-12345-xyz
"@ | Out-File -FilePath .env -Encoding utf8

IMPORTANTE: Reemplaza TU-CONNECTION-STRING-DE-MONGODB-AQUI
            con el que copiaste de MongoDB Atlas

Verificar que se creó:
Get-Content .env


┌────────────────────────────────────────────────────────────────┐
│ PASO 3: DESPLEGAR BACKEND (5-10 min)                          │
└────────────────────────────────────────────────────────────────┘

gcloud app deploy

→ Cuando pregunte la región: selecciona us-central1
→ Cuando pregunte Continue (Y/n)?: escribe Y

ESPERAR 5-10 MINUTOS ☕☕☕

Al terminar, COPIAR la URL que te da:
https://proyectorentaca.uc.r.appspot.com

Probar que funciona:
curl https://proyectorentaca.uc.r.appspot.com


┌────────────────────────────────────────────────────────────────┐
│ PASO 4: CONFIGURAR FRONTEND                                   │
└────────────────────────────────────────────────────────────────┘

cd ..\front\files

@"
NEXT_PUBLIC_API_URL=https://proyectorentaca.uc.r.appspot.com
"@ | Out-File -FilePath .env.production -Encoding utf8

IMPORTANTE: Reemplaza la URL con la que te dio en el paso 3


┌────────────────────────────────────────────────────────────────┐
│ PASO 5: DESPLEGAR FRONTEND (5 min)                            │
└────────────────────────────────────────────────────────────────┘

npm install -g vercel

vercel --prod

→ Set up and deploy? Y
→ Which scope? [presiona Enter]
→ Link to existing project? N
→ Project name? rentacar
→ In which directory? .
→ Override settings? N

ESPERAR 3-5 MINUTOS ☕☕

Al terminar, COPIAR la URL:
https://rentacar-xxxxx.vercel.app


┌────────────────────────────────────────────────────────────────┐
│ PASO 6: ¡PROBAR!                                              │
└────────────────────────────────────────────────────────────────┘

→ Abrir en navegador la URL que te dio Vercel
→ Registrar un usuario
→ Hacer login
→ Ver el catálogo
→ Crear una reserva

¡LISTO! 🎉


┌────────────────────────────────────────────────────────────────┐
│ COMANDOS ÚTILES                                               │
└────────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────────┐
│ SI ALGO FALLA                                                 │
└────────────────────────────────────────────────────────────────┘

ERROR: "Cannot connect to MongoDB"
→ Ve a MongoDB Atlas → Network Access
→ Verifica que esté 0.0.0.0/0
→ Espera 2-3 minutos y reintentar

ERROR: "Project not found"
→ gcloud projects list
→ Copiar el nombre exacto de tu proyecto
→ gcloud config set project NOMBRE-EXACTO

ERROR: "gcloud no se reconoce"
→ Instalar Google Cloud CLI
→ Cerrar y abrir PowerShell de nuevo
